# VkusVill

Extension-навык для интеграции с официальным MCP API ВкусВилл (`https://mcp001.vkusvill.ru/mcp`).

## Возможности

- **Поиск товаров** — по ключевым словам с сортировкой и пагинацией
- **Детали товара** — состав, КБЖУ, цена, рейтинг, условия хранения
- **Корзина** — генерация ссылки для быстрого добавления товаров в корзину

## Архитектура

Навык напрямую вызывает JSON-RPC эндпоинт ВкусВилла через `urllib.request` (zero dependencies).
Протокол: MCP JSON-RPC с session initialization.

API ключи не требуются — эндпоинт публичный.
